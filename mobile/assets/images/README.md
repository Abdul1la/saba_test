# Demo photography

Drop files in with these exact names and they appear in the app. No code
change is needed: `AppNetworkImage` renders a bundled asset and a remote URL
through the same widget, and a file that is not here yet falls back to the
neutral tile the design already draws for a product without a photo.

Square JPGs, 800x800 or larger, except the banners.
